# CardioPredict AI Landing Page

Landing page profissional em Next.js App Router, TypeScript, Tailwind CSS, Framer Motion e lucide-react.

## Como rodar

```bash
npm install
npm run dev
```

Acesse:

```bash
http://localhost:3000
```

## Build de produção

```bash
npm run build
npm run start
```

## Estrutura

```text
app/
  globals.css
  layout.tsx
  page.tsx
components/
  AboutPlatform.tsx
  Benefits.tsx
  DemoAI.tsx
  Footer.tsx
  Header.tsx
  Hero.tsx
  HowItWorks.tsx
  Motion.tsx
  RiskIndicators.tsx
  SectionHeader.tsx
```

## Observação

A seção de Demonstração IA é uma simulação visual para landing page e não possui finalidade médica ou diagnóstica real.
